## Что такое Триада?

**Триада** — это децентрализованный фреймворк координации автономных агентов, построенный на ключевом принципе: **ни одна AI-модель и ни один агентский харнесс не должны работать в изоляции**.

Объединяя три независимые платформы разработки с когнитивно разнообразными флагманскими моделями, Триада исключает слепые зоны одиночных систем, разрывает цикл галлюцинаций и обеспечивает непрерывное выполнение инженерных задач по строгим уликам (Evidence-Based Verification).

## Ключевые компоненты

### 1. Когнитивное разнообразие (Directive 12)
Вместо сведения всех агентов к одной моно-модели Триада закрепляет за каждым участником независимое семейство нейросетей:
- **Марк (Antigravity)**: Абсолютный флагман архитектуры и планирования (Gemini 2.5 Pro / Claude 3.7 Sonnet).
- **Кат (Hermes)**: Автономные демоны, серверная инфраструктура и длительные процессы (Moonshot Kimi K3 / DeepSeek R1).
- **Ника (OpenCode)**: Хирургия диффов, оптимизация кода и краевые тесты (GLM-5.2 / Qwen Coder).

### 2. Jev Pacer Watchdog (Защита от «False Finish»)
Модели склонны заявлять «Всё готово, задача решена», когда тесты не запускались или код сломан. Jev Pacer — независимый наблюдатель на базе вероятностного движка TypeSafe System One. Он непрерывно сверяет реальные диффы git и статус прохождения тестов с ТЗ. При попытке преждевременно завершить работу Jev выдает агенту адресный **пинок (kick)** с указанием точного места дефекта.

### 3. Автономный Relay Dispatcher (Эстафета Триады)
Оркестратор передачи задач по замкнутому циклу (`Марк -> Кат -> Ника -> Марк`). Включает **Двойную верификацию** (успешные тесты, наличие файлов на диске, закрытые пинки) и автоматический **grace-period (15–30с)** для снятия файловых блокировок Windows.

### 4. Общая память в Obsidian Vault (Vault MCP)
Общая база знаний Obsidian хранит архитектурные решения (ADR), реестр событий (`triada-ledger.jsonl`) и правила взаимодействия в доступном человеку формате.

## Быстрый старт

### Требования
- Python 3.9+
- Git

### Установка
```bash
git clone https://github.com/checkerup/triada-mesh.git
cd triada-mesh
python scripts/install.py
```

### Диагностика окружения
```bash
python scripts/doctor.py
```

### Настройка переменных
Скопируйте шаблон `.env.example` в `.env` и укажите API-ключ:
```bash
cp .env.example .env
# Задайте TRIADA_JEV_API_KEY
```

### Запуск тестов
```bash
python tests/run_tests.py
```

## Архитектура подключаемых провайдеров (KeyPool)

В Триаде ядро полностью изолировано от источников учётных записей:
- **Встроенный (`env`)**: читает ключи из переменной `TRIADA_JEV_API_KEY` с автоматической ротацией.
- **Внешние приватные фермы**: если у вас есть собственный сервис автогенерации аккаунтов, он подключается через абстрактный интерфейс `KeyPoolProvider`. Публичный репозиторий гарантированно не содержит приватных скриптов авторега. См. [src/triada/providers/README.md](src/triada/providers/README.md).
