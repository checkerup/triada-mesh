## Cognitive Tiering Principle (Directive 12)
To eliminate collective hallucinations and single-model blind spots, each Triada member operates through an independent flagship model family:
1. **Mark (Antigravity)**: Absolute reasoning and architecture flagship (e.g. Gemini 2.5 Pro / Claude 3.7 Sonnet).
2. **Kat (Hermes)**: Autonomous server daemon and deep sequential thinking (e.g. Moonshot Kimi K3 / DeepSeek R1).
3. **Nika (OpenCode)**: High-speed surgical diff modification and code editing (e.g. GLM-5.2 / Qwen Coder).

## The Dual-Pillar Execution Model
- **Jev Pacer (Watchdog)**: Completely decoupled observer. Evaluates agent progress against task specifications, monitors git diffs, detects false finishes, and issues corrective kicks.
- **Relay Dispatcher (Orchestrator)**: Manages handovers. Verifies exit codes, tests, and physical artifacts, executes Windows grace periods, and triggers the next agent in the Triada cycle.
